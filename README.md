# Dough Bunny

Website for Dough Bunny, a local high-end bakery known for clean, honest ingredients.

## Structure

- `index.html` — single-page site (hero, story, ingredients, menu, gallery, testimonials, visit, contact)
- `css/style.css` — styles (lavender/cream/gold palette matching the brand logo)
- `js/main.js` — nav toggle, scroll reveal, menu tabs, contact form handling
- `assets/images/logo.jpg` — brand logo

## Running locally

This is a static site — no build step required. Serve the directory with any static server, e.g.:

```
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
